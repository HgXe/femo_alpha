# Tutorials

Tutorials are longer-form walkthroughs than the example scripts. They are the best place to start if you want to understand the current FEMO interfaces rather than just run a benchmark case.

## RMShell Tutorial

The RMShell tutorial covers:

- building an `RMShellModel`
- creating isotropic material inputs
- creating field-based load inputs
- solving to a `ShellState`
- using `shell.post.evaluate(...)`, `compute(...)`, and grouped post helpers
- registering custom postprocessing outputs
- using direct generalized load vectors
